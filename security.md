## 🎯 WHAT IS THIS

**Roblox Account Console** is a powerful console-style tool for managing multiple Roblox accounts. Forget about constant logins, manual password entry, and lost sessions.

The extension allows you to **instantly switch between accounts** with one click, keeping all data stored locally and fully secure. Built for streamers, farmers, developers, and active players who handle more than one account.

## ⚙️ HOW IT WORKS

The extension works through the Chrome Extension API and interacts with official Roblox endpoints. When adding an account, you enter the `.ROBLOSECURITY` cookie — the extension validates it, retrieves basic profile information, and stores everything encrypted.

When switching, the extension automatically replaces the cookies in your browser, refreshes the page, and you're instantly logged into the desired account. Everything happens locally without interfering with Roblox's structure.

## ❓ FAQ

**Q: Is it safe to use this extension?**  
A: Yes. All data is stored locally and encrypted. The extension doesn't send anything to external servers.

**Q: How many accounts can I add?**  
A: Unlimited. The extension is optimized for large collections.

**Q: Does it work with 2FA?**  
A: Yes, after the first login, 2FA is saved with the session.

**Q: Can I use the extension on multiple devices?**  
A: Yes, through export/import of settings.

**Q: How do I get the .ROBLOSECURITY cookie?**  
A: Go to Roblox → Open DevTools (F12) → Application tab → Cookies → .ROBLOSECURITY. Copy the value.
